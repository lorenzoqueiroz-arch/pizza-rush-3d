🍕 Pizza Rush 3D — Simulador de Entregas
Pizza Rush 3D é um jogo de simulação em que você assume o papel de um entregador de pizza de moto. Explore a cidade, colete pedidos nas pizzarias, encontre os clientes e ganhe dinheiro para comprar motocicletas melhores.
🎮 Sobre o jogo
O objetivo é realizar entregas pela cidade e evoluir como entregador. Cada pedido concluído rende dinheiro, que pode ser usado para adquirir novas motos e melhorar seu desempenho nas ruas.
Recursos
- Cidade 3D explorável
- Pilotagem de motocicleta
- Coleta e entrega de pedidos de pizza
- Ganhos por entrega e progressão financeira
- Garagem para comprar e trocar de moto
- Trânsito, prédios e pedestres 3D
- Rotas de entrega pela cidade
🕹️ Controles
Tecla	Ação
W ou ↑	Acelerar
S ou ↓	Frear ou dar ré
A ou ←	Virar para a esquerda
D ou →	Virar para a direita
Shift	Nitro
Espaço	Freio de mão
E	Interagir, coletar ou entregar pedido
X	Cancelar pedido
H	Abrir oficina/garagem
R	Reposicionar a moto
P ou Esc	Pausar


Os controles podem variar conforme a versão do jogo.

🚀 Como executar
1. Baixe ou clone este repositório.
2. Extraia os arquivos, caso tenha baixado um ZIP.
3. Abra a pasta do projeto no Visual Studio Code.
4. Abra o arquivo index.html usando a extensão Live Server.
5. Mantenha a conexão com a internet ativa caso a versão utilize bibliotecas ou modelos 3D externos.
Se o projeto incluir o arquivo INICIAR_JOGO.bat, você também pode usá-lo para iniciar o jogo localmente.
